Kontekst projektu: EPLAN SchemaGen — automatyczne generowanie schematów elektrycznych
Cel projektu
Zbudowanie narzędzia które na podstawie prostej konfiguracji (typ napędu, moc, sterowanie) automatycznie generuje gotowy schemat elektryczny w EPLAN Electric P8 2025. Docelowo: agent AI tłumaczy opis słowny lub formularz → generuje schemat → waliduje → eksportuje PDF dla człowieka.

Model danych — XML konfiguracji (gotowy format)
EPLAN Sample Project używa własnego systemu konfiguracji XML. Pliki 3_Sample_StepByStep.xml i 901_Drive_Design.xml pokazują dokładny format:
xml<ConfigurationVariable name="OP_Power_supply_400V">true</ConfigurationVariable>
<ConfigurationVariable name="SE_Drive_Control">Frequency Converter</ConfigurationVariable>
<ConfigurationVariable name="SE_Drive_Type">1,5 kW</ConfigurationVariable>
<ConfigurationVariable name="OP_Transport_1">true</ConfigurationVariable>
<ConfigurationVariable name="SE_Transport_1_Type">0,75 kW</ConfigurationVariable>
Kluczowy wniosek: format danych wejściowych dla agenta jest już zdefiniowany. Agent AI generuje taki XML → skrypt C# go parsuje → EPLAN API wstawia odpowiednie makra. Nie trzeba wymyślać modelu danych od zera.

Pętla walidacji agenta — NIE PDF
PDF to format wyjściowy dla człowieka, nie dla agenta. AI widzi schemat jako obraz — brak semantyki połączeń.
Właściwe sprzężenie zwrotne:
Skrypt generuje schemat w EPLAN
        ↓
EPLAN API eksportuje CSV listy połączeń
        ↓
Agent dostaje CSV + zestaw reguł walidacji:
  "Czy każdy falownik ma DI Ready?"
  "Czy safety ma dwa kanały?"
  "Czy każdy silnik ma PE?"
  "Czy BOM jest kompletny?"
        ↓
Agent zwraca: { errors: [...], warnings: [...], approved: bool }
        ↓
Jeśli approved == false → agent modyfikuje XML konfiguracji → iteruje
        ↓
Jeśli approved == true → EPLAN eksportuje PDF dla człowieka
Eksport CSV w EPLAN API:
csharp// Lista połączeń
new CommandLineInterpreter().Execute("XExport /Format:CSV /Filename:connections.csv");
// PDF dla człowieka
new CommandLineInterpreter().Execute("XPrintPdf /Filename:schemat.pdf");
