  (eksport poprawny: 27 klas, wejście 1280). `terminal_plc` mAP50 ≈ **0.93**, `zlaczka` ≈ 0.15.

## Co naprawione w tej sesji (realne błędy)
1. **Repo „rozsypane" = CRLF.** Dodany `.gitattributes` (LF), znormalizowane końce linii.
2. **Skalowanie bboxów** — idempotencja `scale_annotations.py` (brak podwójnego skalowania).
3. **Labeler pokazywał stare współrzędne** — to był stary szkic w `localStorage`
   (`schemagen:draft:*`). Czyść localStorage / incognito po zmianie danych w bazie.
4. **Trening jednoklasowy** — typ siedział w polu `tag`, nie w klasie. Wprowadzony
   `backend/class_map.py`: `tag` → klasa, klasy budowane z danych (paleta + slug + grupy).
5. **[KLUCZOWE] export_onnx ignorował --version** — brał zawsze `runs/symbols_v1`
   (stary, jednoklasowy `element`). Stąd „motor/element wszędzie", false-positives, złe miejsca.
   Naprawione: wybór wag wg `data/runs/<version>/weights/best.pt`.
6. **Detektor: złe pozycje** — letterbox był czarny/lewy-górny zamiast szary(114)/wyśrodkowany
   jak w ultralytics. Naprawione (z korektą offsetu).
7. **Detektor: nazwy klas** — czytane z metadanych modelu ONNX, nie z globalnego
   `symbol-classes.yaml` (który się nadpisuje). Koniec rozjazdu indeks↔nazwa.
8. **preview_detection** — brakujące importy (NameError); + obsługa GPU (DLL z torch cu121).

## Narzędzia (scripts/)
- `class_report.py --min-count 5` — strony, bboxy, instancje per klasa; co wypada.
- `relabel_tool.py [--class X]` → galeria wycinków + dropdown klas → `reassignments.json`.
- `apply_reassign.py [--file ...] [--apply]` — zapis poprawek klas do bazy (dry-run domyślnie).
- `autolabel.py --all-unlabeled --conf 0.3 [--apply] [--force]` — model proponuje bboxy
  na nowych stronach → baza → przegląd w labelerze. (Active learning, x3 dane.)
- `preview_batch.py [--version] [--conf] [--limit] [--offset]` — galeria detekcji + metryka per klasa.
- `review_detections.py` — pojedyncze detekcje, klik OK/ZLE, eksport ocen.
- `visualize_bboxes.py` — bboxy z bazy na stronach (kontrola skalowania).
- `visualize_yolo_dataset.py` — etykiety YOLO 1:1 jak widzi model (kontrola normalizacji).
- `visualize_class_crops.py [--class X] [--pad]` — wnętrza bboxów pogrupowane per klasa.

## Workflow (powtarzalny cykl powiększania danych)
```powershell
# 1. nowe strony: propozycje modelu -> baza
python scripts/autolabel.py --all-unlabeled --conf 0.3 --apply
python -m labeler.app                 # przejrzyj, popraw, usun, Ctrl+S  (incognito!)

# 2. popraw błędne klasy istniejących (opcjonalnie)
python scripts/relabel_tool.py        # -> data/output/reassignments.json
python scripts/apply_reassign.py --apply

# 3. eksport + trening + onnx
python scripts/class_report.py --min-count 5
python -m train.dataset_export --min-count 5
python -m train.train_symbols --name symbols_mc_vN          # [--degrees 180 = test rotacji]
python -m train.export_onnx --version symbols_mc_vN          # USTAWIA aktywny model

# 4. ocena (wzrokowa, nie tylko val mAP)
python scripts/preview_batch.py --version symbols_mc_vN --conf 0.25 --limit 30 --offset 15
python scripts/review_detections.py --version symbols_mc_vN --conf 0.25 --limit 30 --offset 15
```
